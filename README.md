# Neeraj Gundam — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. The content is based on the resume supplied for this conversation.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

No build tools or package installation are required.

## Customize before publishing

- Verify the email address, phone number, education dates, CGPA, and all project details.
- Add GitHub repository links to the project cards when available.
- Add a downloadable resume PDF link if desired.
- Add project screenshots or live-demo links only after verifying they work.

## Deploy

You can publish this static site using GitHub Pages, Netlify, or Vercel. Upload `index.html`, `style.css`, `script.js`, and this README to your repository.
